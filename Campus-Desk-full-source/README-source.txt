Campus Desk - Project Source
============================

Current application source, configuration, tests and design notes.
Independent student project. Not an official school website.

Requirements: Node.js and npm.
Install dependencies: npm install
Development server: run npm run dev from this project folder.
Open the localhost URL printed by Vite. Do not double-click index.html.
Local production preview build: npm run build:local (the AI proxy runs only on the dev server).
Hosted AppDeploy build: vite build

Project files:
 - DESIGN.md
 - backend/index.ts
 - docs/design-tooling-notes.md
 - index.html
 - package.json
 - postcss.config.js
 - src/local-appdeploy-client.ts
 - src/main.ts
 - src/styles.css
 - tailwind.config.js
 - tests/tests.json
 - tsconfig.json
 - vite.config.ts

No API key is included. Configure your own AI provider credentials in app Settings.
